# BrowserSelector v0.2.0 リリースノート

**リリース日**: 2026年8月16日
**バージョン**: v0.2.0
**コードネーム**: ".NET 10 & Glass UI"

## 🎉 概要

BrowserSelector v0.2.0は、.NET 10への移行とガラスUI刷新を中心とした大型アップデートです。Mica/Acrylicバックドロップによる奥行きのある外観、ブラウザタイルのホバーアニメーション、フルキーボード操作対応、起動高速化、起動制御系（カウントダウン自動起動・トレイ常駐・CLIオプション）、設定画面の刷新など、Phase A〜G（G-1ドキュメント整合を除き完了）にわたる作業をまとめてリリースします。

## ✨ 主な変更点

### 🏗️ .NET 10移行
- 全プロジェクトのターゲットフレームワークを`net8.0-windows`から`net10.0-windows`へ移行
- ビルド警告0件を維持したまま移行を完了

### 🎨 ガラスUI（Mica/Acrylicバックドロップ）
- ウィンドウ背景描画方式として`Mica`（既定の不透明多層ブラー）・`Acrylic`（半透明・強めのブラー）・`MicaAlt`（タブ付きウィンドウ向けの濃いMica）に対応
- DWM非対応環境向けに半透明単色ブラシ、ハイコントラスト・低スペック環境向けに完全不透明モードのフォールバックを用意
- 設定画面の新設「外観」タブから、バックドロップ方式・不透明度・角丸半径・タイトルバー表示切替・常に最前面・テーマ（ライト/ダーク/システム追従）を一括調整可能

### 🧩 ブラウザタイル刷新
- タイルのホバーアニメーション、フォーカスリング、ホットキーバッジ、奥行き表現を追加
- グリッドレイアウトがウィンドウリサイズに追従するレスポンシブ対応

### ⌨️ キーボード操作対応
- `Esc`（閉じる）、`Enter`/`Space`（起動）、矢印キー/`Tab`（グリッド移動）、`1`-`9`・`A`-`Z`（ブラウザ別ホットキー）、`Ctrl`+`,`（設定を開く）、`Ctrl`+クリック/`Ctrl`+`Enter`（起動後閉じない）に対応
- マウス操作なしでの完結利用が可能に

### 🚀 起動高速化
- 単一インスタンス化（`ISingleInstanceManager`）により多重起動を防止し、後続起動時はURLを既存インスタンスへ転送
- アイコンキャッシュ（`IIconCacheService`）によるアイコン抽出コストの削減
- ReadyToRunパブリッシュによる起動時JITコストの削減

### 🕹️ 起動制御系
- カウントダウン自動起動: 起動後、指定秒数の経過で選択中（またはデフォルト）のブラウザを自動起動
- トレイ常駐: システムトレイに常駐してバックグラウンド待機
- CLIオプション: `-d`/`--delay`、`-b`/`--browser`、`--silent`、`--auto-launch`、`-h`/`--help`、`-v`/`--version`

### ⚙️ 設定画面刷新
- 「外観」タブ新設（上記ガラスUI関連設定）
- 「アクセシビリティ」タブ復活（フォーカス表示機能の設定等）
- 「バージョン情報（About）」セクション新設。`Directory.Build.props`の`Version`を単一の情報源として、インストーラー（`.iss`）の`MyAppVersion`へビルド時自動注入

### 🖼️ 新ロゴ
- アプリケーションロゴ・アイコンセットを刷新

### 🔧 品質・CI/CD
- Core/Servicesの主要インターフェース（`IUpdateService`/`IUrlRuleService`/`IProtocolHandler`/`IRegistryService`/`ILogService`/`ICustomLanguageService`ほか）のXMLコメント文字化けを修復
- `release.yml`を新規作成し、タグpush（`v*`）を起点にInno Setupインストーラーをビルドし、GitHub Releaseへ自動公開する仕組みを整備
